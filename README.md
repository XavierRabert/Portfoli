## ⚙️ Engineering Best Practices

To maintain professional standards, this repository implements:

- **CI/CD Pipeline**: GitHub Actions automatically validates formatting, types, and build stability on every push.
- **Pre-commit Hooks**: Powered by Husky, preventing any commit that doesn't pass TypeScript and linting checks.

### Local Setup

```bash
# Install dependencies
pnpm install

# Run in development mode
pnpm dev

# Manual code validation
pnpm run typecheck && pnpm run check
```
